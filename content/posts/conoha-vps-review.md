このブログは、2026年8月の終わりからConoHa VPSの上で動いています。使い始めて1か月半たったので、実際に使ってみてどうだったかを正直に書きます。

先に結論です。

| 項目 | 結論 |
|---|---|
| よかったところ | 料金のわりに十分使える。契約が短い時間で終わる。サイトが止まったことがない |
| 困ったところ | セキュリティグループの仕組み。管理画面の情報が多くて、初心者はどこを触ればいいか迷う |
| 向いている人 | 自分でサーバーを立ててみたい人。好きなデザインでブログやサイトを作りたい人 |
| 向いていない人 | とにかく早くWordPressでブログを始めたい人 |

## 使っている構成

| 項目 | このブログ |
|---|---|
| 使い始め | 2026年8月の終わり |
| プラン | メモリ1GB |
| OS | Ubuntu 24.04 |
| 料金タイプ | まとめトク(36か月) |
| 払った金額 | 16,179円(36か月分を一括) |
| 動かしているもの | Nginx + Hugoで作った静的サイト(このブログ) |

36か月分で16,179円なので、**1か月あたり約450円**です。同じ1GBプランを時間課金で使うと、契約したときの表示で月1,064円が上限でした。料金は変わることがあるので、申し込む前に公式サイトで最新の金額を確かめてください。

## よかったところ

### 料金のわりに十分使える

月450円ほどで、自分専用のサーバーが1台まるごと使えます。このブログのような静的サイトなら、1GBのメモリでも余裕があります。サイトを置くだけでなく、Linuxのコマンドを打ったり、Nginxの設定を書き換えたりと、勉強用のサーバーとしても使えるので、学生の自分にはちょうどいい値段でした。

### 契約がすぐに終わる

アカウントを作って、プランとOSを選んで、「追加」を押すだけです。サーバーが起動するまで、待たされた記憶がありません。初めてのVPSでしたが、契約のところでストレスを感じることはありませんでした。手順は [第3回 ConoHa編](/posts/series-03-conoha/) に画面付きでまとめています。

### サイトが止まったり、重くなったりしたことがない

1か月半のあいだ、サイトが重いと感じたことも、ConoHa側の都合で止まったこともありません。

ただ、このブログはまだアクセスが少なく、中身も軽い静的サイトです。アクセスの多いサイトやWordPressを動かしたときにどうなるかは、まだ分かりません。

### ブラウザから直接サーバーに入れる「コンソール」に助けられた

ConoHaの管理画面には、SSHを使わずに、ブラウザからサーバーにログインできる「コンソール」という機能があります。

SSHがまったくつながらなかったとき、コンソールで入れたおかげで「サーバー自体は動いている」と分かり、原因を絞り込めました。設定を間違えてSSHで入れなくなったときの、最後の入口にもなります。

## 困ったところ

### セキュリティグループの仕組み

一番ハマったのはここです。ConoHa VPSでは、サーバーの中の設定とは別に、管理画面で「セキュリティグループ」を付けないと通信が通りません。最初から付いている `default` は「全部許可」に見えるのに、SSH用の `IPv4v6-SSH` と、Web用の `IPv4v6-Web` を別に追加しないと、SSHもサイトもつながりませんでした。

これに気づくまで、丸1日かかりました。くわしくは [ConoHa VPSでSSH接続できずハマった話](/posts/ssh-conoha-hamatta/) に書いています。これから契約する人は、サーバーを作るときに2つとも追加しておけば、同じところではハマりません。

### 管理画面は見やすいけど、情報が多い

画面のデザインはすっきりしていて見やすいです。ただ、表示される項目が多いので、初めての人は「どこを触ればいいのか」で迷うと思います。自分も最初は、プランやオプションの意味が分からず、契約画面で手が止まりました。

迷ったら、[第3回](/posts/series-03-conoha/) の表のとおりに選べば大丈夫です。

### 困ったら、自分で調べて直すしかない

VPSなので、サーバーの中で起きたトラブルは自分で原因を探して直します。レンタルサーバーのように、サポートに聞けば直してもらえるわけではありません。

自分は、分からないことをAI(Claude)に聞きながら進めたので、ほとんどのことは自分で解決できました。エラーの文章をそのまま見せて質問すると、原因の見当がつくまでがかなり早くなります。ただし、IPアドレスやパスワードが写った部分は、貼る前に必ず消してください。

## 36か月のまとめ払いは失敗だった?

契約したときは、試す段階なのに勢いで36か月払いにしてしまい、[第3回](/posts/series-03-conoha/) では「一番の反省点」と書きました。初めての人には、今でも時間課金から始めることをおすすめします。

ただ、自分自身は今、**このまとめ払いに満足しています。** 少なくとも就職活動が終わるまでは、このサイトを動かし続けるつもりだからです。続けると決めた人にとっては、1か月あたり450円ほどになるまとめ払いは、結果的にお得でした。

「まず時間課金で試す → 続けると決めたら、まとめ払いに切り替える」が、一番損をしない順番だと思います。

## 向いている人・向いていない人

**向いている人**
- 自分でサーバーを立ててみたい人
- 好きなデザインで、ブログやサイトを作って動かしたい人
- Linuxやサーバーの勉強を、本番に近い形でしたい人

**向いていない人**
- とにかく早く、WordPressでブログを始めたい人
- エラーが出たときに、自分で調べて直すのがつらい人

WordPressで早く始めたい人には、VPSよりも、WordPress向けのレンタルサーバーの方が合っています。どちらにするか迷っている人は、[第1回 計画編](/posts/series-01-keikaku/) で、費用と手間を比べています。

## 申し込むときの注意

1. **最初は時間課金を選ぶ。** 続けると決めてから、まとめ払いに切り替える
2. **セキュリティグループで `IPv4v6-SSH` と `IPv4v6-Web` を追加する。** 付け忘れると、SSHもサイトもつながらない
3. **rootパスワードは、パスワード管理アプリに保存する。** スクリーンショットにも写さない
