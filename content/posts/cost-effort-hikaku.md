VPS契約からAdSenseの税務情報設定まで、一通りの作業が終わったので、ここまでに実際にかかった**お金**と**時間・労力**を、誤魔化さずに棚卸ししてみます。あわせて、もし最初からWordPress(共用レンタルサーバー)を選んでいたらどうだったかも比較します。

> 表の中で**太字**にしている項目は、労力が重かったもの、または今後も継続的にお金がかかる(かかる予定の)ものです。

## 費用の横並び比較

| 項目 | 今回(VPS + Hugo) | WordPress(共用レンタルサーバー)だったら |
|---|---|---|
| サーバー代(初期) | 16,179円(36ヶ月まとめ払い) | 無料〜数百円のことが多い |
| サーバー代(継続) | 時間課金なら月数百円で済んだはず | **月1,000〜1,300円程度が相場** |
| ドメイン(初年度) | 0円(キャンペーン) | 今回とほぼ同条件 |
| ドメイン更新料(2年目以降) | **約1,728円/年** | **同程度、必要** |
| SSL証明書 | 0円(Let's Encrypt) | 0円(多くのレンタルサーバーで無料提供) |
| Search Console/Analytics | 0円 | 0円 |
| AdSense・アフィリエイト登録 | 0円 | 0円 |
| プラグイン・有料テーマ | 不要 | **凝ったデザイン・機能を求めると発生しがち** |
| Claude(構築・記事作成に使用) | **Proプランなら月額$20(約3,000円前後)** | 使うとすれば同程度 |

### 金額だけまとめると

| | 初期費用 | 今後の年間固定費 |
|---|---|---|
| 今回(VPS + Hugo) | 16,179円 | 約1,728円(ドメイン更新) + Claude利用料(使う場合) |
| WordPressだったら | 無料〜数百円 | 年12,000〜16,000円程度(サーバー代) + ドメイン更新料 |

意外にも、**今回のVPSの初期費用(16,179円)は「まとめトク」を選んでしまった一時的な出費**であり、本来は時間課金で数百円から始められました。一方、WordPress用の共用レンタルサーバーは初期費用こそ安いものの、**月額のサーバー代が継続的にかかる**ため、長期的に見るとむしろ今回より高くつく可能性もあります。

## 労力の横並び比較

| 項目 | 今回(VPS + Hugo) | WordPress(共用レンタルサーバー)だったら |
|---|---|---|
| 環境構築 | 軽い(インストール、フォルダ移動の混乱) | 軽い(管理画面からワンクリック導入が多い) |
| SSH接続・ファイアウォール | **重い(セキュリティグループの仕様に気づくまで丸1日)** | ほぼ意識する必要がない |
| Webサーバー公開・権限 | **中〜重い(403エラーが繰り返し発生)** | 該当する概念自体が存在しない |
| 文字コード・HTTPS化 | **重い(文字化け事件、baseURL不整合)** | 管理画面上での編集が基本、まず起きない |
| 記事公開の手順 | 書く→ビルド→転送→権限修正、と多段階 | 管理画面でボタンを押すだけ |
| プラグイン・脆弱性対応 | 不要(静的サイトのため) | **必要(放置するとセキュリティリスク)** |
| Search Console/Analytics導入 | 中程度(HTTPS未対応での引っかかり) | 軽い(プラグインで比較的簡単) |
| AdSense・税務情報設定 | 中程度(専門用語の多さ、W-8BENの入力) | 今回と同程度(サイト構成に関わらず必要な手続き) |
| 学べる技術要素 | Linux・SSH・Nginx・DNS・証明書など広範囲 | ほぼ「WordPressの使い方」に閉じる |
| **総合的な労力** | **重い(原因不明のエラーに向き合う時間が長い)** | 軽い(管理画面中心で完結) |

体感として、**技術的な難しさよりも「原因不明のエラーに何時間も向き合う」時間の方が圧倒的に長かった**というのが正直な感想です。特にSSHとドメインまわりは、原因が分かってしまえば数分で直る内容なのに、そこに辿り着くまでに何時間もかかりました。

## 総括

**「早く収益化したい・楽に更新したい」という基準だけで見れば、WordPress(共用レンタルサーバー)の方が圧倒的に効率的だった**というのが、正直な結論です。今回のトラブルの多くは、WordPressであればそもそも発生し得ないか、事業者側が自動で解決してくれる類のものでした。

一方で、今回の目的は「インフラエンジニアを目指す上での実践経験を積むこと」でした。その観点で見ると、

- SSH・ファイアウォールの二重構造
- DNSの仕組みと反映の仕組み
- 証明書・暗号化通信の実際の挙動
- 文字コードという、普段意識しない領域の落とし穴

といった、**WordPressを使っていたら一生触れずに済んでいたかもしれない技術要素**に、実体験として向き合うことができました。

金額面では、初期費用の16,179円に加えて、今後は**ドメイン更新料(年約1,728円)**と、**AIツールを使い続ける場合の月額利用料**が、地味だが継続的にかかる固定費として残ります。これらを含めてもなお、目的が「学習」である以上、この遠回りには十分価値があったと感じています。

もし今後、「とにかく早くブログで収益を出したい」というだけの目的で始める人には、正直にWordPress(またはそれに近いホスティングサービス)をすすめると思います。逆に、「壊しながら学びたい」という人には、今回の経験は迷わずおすすめできます。
