この記事を読み終えると、ブログを作り始める前に決めておくべき4つのこと(目的・方式・サーバー・ドメイン)が決められるようになります。

先に結論を書くと、こうなります。

- **早く記事を書いて稼ぎたい** → WordPress(レンタルサーバー)
- **サーバーの仕組みを学びたい・就活でアピールしたい** → 自作VPS

このブログは後者で、VPS(自分専用の仮想サーバー)を借りて、Hugoという道具でサイトを一から作りました。実際にやってみて分かった費用と手間も、この記事の後半で全部出しています。

## 決める順番

### 1. 目的を決める

次のどれが一番の目的かを先に決めます。ここで選ぶ方式が変わります。

- 早く記事を書いて稼ぎたい → WordPress
- サーバーの仕組みを学びたい → 自作VPS
- 就活のポートフォリオにしたい → 自作VPS

### 2. 方式を決める

|  | WordPress(レンタルサーバー) | 自作VPS |
|---|---|---|
| 公開までの時間 | 1時間ほど | 数日〜 |
| 月額の目安 | 500〜1,300円 | 700〜1,000円 |
| 必要な知識 | ほぼ不要 | Linux・サーバーの基礎 |
| 壊れたとき | サポートに聞ける | 自分で直す |
| 学べること | 記事の書き方・SEO | サーバー構築・インフラ全般 |

このブログは「インフラを学ぶ」が目的なので、自作VPSを選びました。

#### VPSとレンタルサーバーは何が違うのか

契約前は「root権限(サーバーの管理者の権限)があるかないか」という説明で分かった気になっていました。

| | 共用レンタルサーバー | VPS |
|---|---|---|
| 権限 | 管理画面でできることだけ | サーバーの管理者権限(root)が丸ごともらえる |
| 自由度 | 用意された機能の中で | Nginxなど、何でも自分で入れられる |
| 設定するもの | ほぼ管理画面のボタンで済む | Webサーバー、ファイアウォール、証明書まで全部自分 |

実際に運用してみて分かったのは、**自由ということは、全部自分の責任ということ**でした。

- Webサーバー(Nginx)のインストールから、ファイアウォール、HTTPSの証明書まで、すべて自分の手で入れる
- `*** System restart required ***` のようなOSの更新のお知らせも、自分で判断して対応する
- 「つながらない」ときに疑う場所が、サーバー本体・サーバーの中のファイアウォール・ConoHa側のファイアウォール・DNS・自分のネットワークと、一気に増える

レンタルサーバーなら事業者がやってくれる部分を、全部自分で抱えることになります。その代わり、ここで触った技術はそのまま仕事(インフラエンジニア)で使う知識と重なっています。

#### 静的サイト(Hugo)とWordPressは何が違うのか

WordPressは、記事をデータベースに入れておき、読まれるたびにページを組み立てます。Hugoは、書いた記事を前もって全部HTMLのファイルにしておき、それをそのまま配るだけです(これを静的サイトと呼びます)。

始める前の予想と、数週間運用してみた実感を並べるとこうなりました。

| 観点 | 始める前の予想 | 実際に運用してみて |
|---|---|---|
| セキュリティ | 静的サイトの方が安全 | 予想どおり。プラグインの脆弱性対応やログイン画面への攻撃対策が要らず、起きたトラブルはほぼ自分の操作ミスだった |
| 表示の速さ | 静的サイトの方が速い | 予想どおり。データベースを通らないぶん軽い |
| 更新の手間 | WordPressの方が楽 | 手順を覚えれば数分で終わる。ただ、**覚えるまでのコストは予想よりずっと高かった** |
| 想定外だったこと | — | ファイルを送るたびに読み取りの権限がおかしくなる、という問題に何度も当たった |

「楽に更新したい」ならWordPressが上、という予想は変わりませんでした。一方で「インフラを学びながら発信する」という目的には、予想以上に合っていました。

### 3. サーバーを決める

VPSを選ぶ場合、日本国内だとConoHa・さくらのVPS・Xserver VPSあたりが候補になります。

このブログはConoHa VPSにしました。管理画面が日本語で分かりやすく、初期費用がかからないためです。

### 4. ドメインを決める

`.com` を選んでおけば間違いありません。お名前.comなどの登録サービスで取得します。`.com` にした理由は [第4回 ドメイン編](/posts/series-04-domain/) に書いています。

## 実際にかかった費用(このブログの場合)

VPSの契約から、AdSenseの税務情報の設定まで一通り終わった時点で、お金を棚卸ししました。太字は、これからも毎年(毎月)かかるものです。

| 項目 | このブログ(VPS + Hugo) | WordPress(共用レンタルサーバー)だったら |
|---|---|---|
| サーバー代(最初) | 16,179円(36か月分をまとめ払い) | 無料〜数百円のことが多い |
| サーバー代(毎月) | 時間課金なら月数百円で済んだはず | **月1,000〜1,300円ほど** |
| ドメイン(1年目) | 0円(キャンペーン) | ほぼ同じ |
| ドメインの更新(2年目から) | **年1,728円ほど** | **同じくらい必要** |
| SSL証明書(HTTPS) | 0円(Let's Encrypt) | 0円のところが多い |
| Search Console・Analytics | 0円 | 0円 |
| AdSense・A8.netの登録 | 0円 | 0円 |
| 有料テーマ・プラグイン | 不要 | **凝りだすとかかりがち** |
| AI(Claude)の利用料 | **使う場合、Proプランで月20ドル(3,000円前後)** | 使うなら同じ |

金額だけ見ると、こうなります。

| | 最初にかかったお金 | これから毎年かかるお金 |
|---|---|---|
| このブログ(VPS + Hugo) | 16,179円 | ドメイン更新 約1,728円 + AIを使うならその利用料 |
| WordPressだったら | 無料〜数百円 | サーバー代 年12,000〜16,000円ほど + ドメイン更新料 |

16,179円は、勢いで「まとめトク」の36か月払いを選んでしまったための一時的な出費です(詳しくは [第3回](/posts/series-03-conoha/))。時間課金なら数百円から始められました。逆にWordPress用のレンタルサーバーは、最初は安くても月額がずっとかかるので、長い目で見るとVPSより高くなることもあります。

## 実際にかかった手間(このブログの場合)

お金よりも差が大きかったのは手間です。

| 作業 | このブログ(VPS + Hugo) | WordPressだったら |
|---|---|---|
| Hugoのインストール | 軽い(フォルダの場所で少し迷った) | 管理画面からワンクリックのことが多い |
| SSH接続・ファイアウォール | **重い。ConoHaの仕様に気づくまで丸1日** | ほぼ意識しない |
| サイトの公開・ファイルの権限 | **中〜重い。403エラーが何度も出た** | そもそもこの作業がない |
| 文字コード・HTTPS化 | **重い。設定ファイルの文字化けと、baseURLのずれ** | 管理画面で編集するので、まず起きない |
| 記事の公開 | 書く → 変換 → 転送 → 権限を直す | 管理画面のボタンを押すだけ |
| プラグインの更新・脆弱性対応 | 不要 | **必要。放っておくと危ない** |
| Search Console・Analytics | 中くらい(HTTPSが済んでいなくてつまずいた) | プラグインで比較的かんたん |
| AdSense・税務情報 | 中くらい(専門用語が多い) | 同じ(サイトの作り方に関係なく必要) |

体感として、**技術的な難しさよりも「原因の分からないエラーと向き合う時間」の方が圧倒的に長かった**です。特にSSHとドメインまわりは、原因が分かれば数分で直る内容なのに、そこにたどり着くまでに何時間もかかりました。

## 自作VPSにしてよかったか

「早く稼ぎたい・楽に更新したい」という基準だけなら、**WordPressの方が圧倒的に効率的でした**。このブログで起きたトラブルの多くは、WordPressならそもそも起きないか、事業者が直してくれるものです。

それでも、目的が学習だったので後悔はしていません。WordPressを使っていたら触らずに済んでいたかもしれない、次のようなことを体験として覚えられました。

- SSHと、2重になっているファイアウォールの仕組み
- DNSの設定と、反映を待つということ
- HTTPSの証明書が実際にどう動くか
- 文字コードという、普段は意識しない落とし穴
- 「動かない」の原因を自分で切り分けるやり方

これからブログを始める人には、「とにかく早く収益を出したい」ならWordPressを、「壊しながら学びたい」なら自作VPSをすすめます。

## つまずきやすい注意点

**ドメインは1年目の料金で判断しない**

1年目が数百円でも、2年目以降は1,500円前後に上がるものがあります。更新料を必ず確認してください。

**「無料お試し」に注意**

ドメイン取得時、ホームページ作成サービスなどが初期チェック済みで付いてくることがあります。無料期間が終わると自動で課金されるので、申し込み画面のチェックは全部外してください。

**VPSは壊れても誰も直してくれない**

サポートに聞けば直るレンタルサーバーとは違い、VPSは自分で原因を調べて直します。学習目的でないなら、素直にWordPressを選んだほうが早いです。

**料金は変動します**

ここに書いた金額は目安です。契約前に必ず公式サイトで最新の料金を確認してください。
