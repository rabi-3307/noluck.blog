この記事を読み終えると、ブログを作り始める前に決めておくべき4つのこと(目的・方式・サーバー・ドメイン)が決められるようになります。

## 決める順番

### 1. 目的を決める

次のどれが一番の目的かを先に決めます。ここで選ぶ方式が変わります。

- 早く記事を書いて稼ぎたい → WordPress
- サーバーの仕組みを学びたい → 自作VPS
- 就活のポートフォリオにしたい → 自作VPS

### 2. 方式を決める

|  | WordPress(レンタルサーバー) | 自作VPS |
|---|---|---|
| 公開までの時間 | 1時間ほど | 数日〜 |
| 月額の目安 | 500〜1,300円 | 700〜1,000円 |
| 必要な知識 | ほぼ不要 | Linux・サーバーの基礎 |
| 壊れたとき | サポートに聞ける | 自分で直す |
| 学べること | 記事の書き方・SEO | サーバー構築・インフラ全般 |

このブログは「インフラを学ぶ」が目的なので、自作VPSを選びました。

### 3. サーバーを決める

VPSを選ぶ場合、日本国内だとConoHa・さくらのVPS・Xserver VPSあたりが候補になります。

このブログはConoHa VPSにしました。管理画面が日本語で分かりやすく、初期費用がかからないためです。

### 4. ドメインを決める

`.com` を選んでおけば間違いありません。お名前.comなどの登録サービスで取得します。

## つまずきやすい注意点

**ドメインは1年目の料金で判断しない**

1年目が数百円でも、2年目以降は1,500円前後に上がるものがあります。更新料を必ず確認してください。

**「無料お試し」に注意**

ドメイン取得時、ホームページ作成サービスなどが初期チェック済みで付いてくることがあります。無料期間が終わると自動で課金されるので、申し込み画面のチェックは全部外してください。

**VPSは壊れても誰も直してくれない**

サポートに聞けば直るレンタルサーバーとは違い、VPSは自分で原因を調べて直します。学習目的でないなら、素直にWordPressを選んだほうが早いです。

**料金は変動します**

ここに書いた金額は目安です。契約前に必ず公式サイトで最新の料金を確認してください。

かかった費用と労力の全体は [ここまでにかかった費用と労力](/posts/cost-effort-hikaku/) にまとめています。
