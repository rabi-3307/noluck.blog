この記事を読み終えると、ConoHa VPSでサーバーが起動し、接続先のIPアドレスが分かる状態になります。

## 操作手順

1. ConoHaの公式サイトで「今すぐお申し込み」からアカウントを作成する(メールアドレス・パスワード・電話番号の認証)
2. 支払い方法(クレジットカード)を登録する
3. 管理画面で「サーバー追加」を押す
4. 次のように選ぶ

| 項目 | 選ぶもの |
|---|---|
| サービス | VPS |
| プラン | メモリ1GB |
| イメージ | Ubuntu 24.04 |
| rootパスワード | 自分で決める(パスワード管理アプリに保存) |
| SSH Key | 今は「使用しない」でOK(第5回で設定) |

5. セキュリティグループで、`default` に加えて `IPv4v6-SSH` と `IPv4v6-Web` を追加する
6. 「追加」を押す
7. サーバー一覧でステータスが「起動中」になったら、IPアドレス(`xxx.xxx.xxx.xxx` の形)をメモする

### 料金タイプの選び方

| 料金タイプ | 向いている人 |
|---|---|
| 時間課金 | まず試してみたい人 |
| まとめトク(長期割引) | 続けると決めた人 |

最初は時間課金で始めて、続けると決めてから長期割引に切り替えるのが安全です。

## つまずきやすい注意点

**セキュリティグループを付けないとつながらない**

ConoHa VPS 3.0では、サーバーの中の設定とは別に、管理画面のセキュリティグループで通信を許可する必要があります。`IPv4v6-SSH` が無いとSSHがタイムアウトし、`IPv4v6-Web` が無いとサイトが表示されません。これで数日ハマりました。詳しくは [ConoHaでSSHがつながらなかった話](/posts/ssh-conoha-hamatta/) と [ufwとセキュリティグループの違い](/posts/ufw-vs-secgroup/) へ。

**サーバーを「停止」しても料金はかかる**

時間課金は、サーバーを削除するまで課金が続きます。使わないなら削除してください。

**rootパスワードは誰にも見せない**

スクリーンショットを人に送るときも、パスワードやIPアドレスが写っていないか確認してください。

**画面の見た目は変わることがある**

ボタンの名前や配置は変更されることがあります。見つからないときは公式のマニュアルを確認してください。
