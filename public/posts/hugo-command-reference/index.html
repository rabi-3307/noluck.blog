Hugoコマンド逆引き表(意味と使うタイミングまとめ)

2026.09.05

Hugoを触り始めてから、同じコマンドを何度も打っているうちに「これ何のためのコマンドだっけ」と忘れることが多かったので、意味と使うタイミングを一覧にまとめておきます。

前提:コマンドはどこで打つのか

すべて、hugo.tomlがあるフォルダ(プロジェクトのルート)まで移動してから実行します。

cd "C:\Users\user\...\yourlog-site"

hugoから始まるコマンドを打ってUnable to locate config fileというエラーが出たら、大抵はこのcdを忘れているサインです。

コマンド一覧

コマンド 意味 使うタイミング
hugo new site フォルダ名 新しいHugoサイトの骨組みを作る 最初にサイトを立ち上げるとき、一度きり
hugo new posts/ファイル名.md 新しい記事ファイルを、決まった書式(Front Matter)付きで自動生成する 新しい記事を書き始めるとき
hugo server 手元のPCだけで見られるプレビュー用サーバーを起動する 記事やデザインの変更を、公開前に確認したいとき
hugo(オプション無し) 本番公開用の完成品(publicフォルダ)を生成する 記事が書き終わって、実際にサーバーへアップロードする直前
hugo --minify hugoと同じだが、HTML/CSSの無駄な空白などを削って軽量化する 本番公開時、こちらを使うとページの読み込みが少し速くなる

hugo serverとhugoの違い(混同しやすいポイント)

これが一番間違えやすいポイントでした。

hugo server hugo
保存先 メモリ上(ディスクは更新されない) publicフォルダに書き込まれる
見られる範囲 自分のPCだけ(localhost:1313) 誰でも見れるわけではなく、あくまでファイルを生成するだけ
実際に世界に公開するには このコマンドだけでは公開されない 生成されたpublicフォルダを、別途サーバーに転送する必要がある

hugo serverは毎回publicフォルダを更新するわけではない、という点を最初理解しておらず、「保存したのに変わらない」と勘違いしたことがありました。プレビュー確認はhugo server、実際に公開するファイルを作るのはhugo、と役割がはっきり分かれています。

サーバー停止のコマンド

操作 意味
Ctrl + C hugo serverを停止する(ターミナルにフォーカスした状態で押す)

覚え方のコツ

  • 「server」のsは「see(確認する)」のsだと思うと覚えやすい → 確認したいときはserverを付ける
  • 何も付けないhugoは「完成品を出荷する」イメージ

この2つさえ区別できれば、Hugoの基本操作はほぼ迷わなくなると思います。
