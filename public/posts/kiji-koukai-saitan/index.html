【操作だけ】記事を公開する手順(PowerShellの開き方から)

2026.09.07

上から順番に、書かれている通りにクリック・コピペするだけで公開できます。

⚠️ 文中の xxx.xxx.xxx.xxx は、あなた自身のVPSのIPアドレスに置き換えて使ってください。IPアドレスは他人に見せてはいけない情報なので、この記事にはそのまま載せていません。

準備:PowerShellを開く

  1. パソコンの画面下にある検索アイコン(虫眼鏡マーク)か、フォルダのアイコンをクリックして「エクスプローラー」を開く
  2. yourlog-site というフォルダを探してダブルクリックで開く
  3. 開いたウィンドウの一番上、住所のようなものが書かれている場所(アドレスバー)をクリックする
  4. 文字が全部選択された状態になるので、キーボードで powershell と入力する
  5. Enterキーを押す
  6. 黒い画面(これがPowerShellです)が開く

これで準備完了です。この後の操作は、すべてこの黒い画面の中で行います。

ステップ1:記事を確認する

  1. 黒い画面をクリックして、そこに以下の文字をコピーする(この記事の文字をドラッグして選択 → 右クリック →「コピー」、またはキーボードで Ctrl + C)
hugo server
  1. 黒い画面の中で右クリックする(貼り付けられる)、または Ctrl + V
  2. Enterキーを押す
  3. 画面に文字がいろいろ出てきて、最後に以下のような表示が出たら成功
Web Server is available at http://localhost:1313/
  1. ブラウザ(Chromeなど)を開いて、上のアドレスを入力する場所に以下を入力してEnter
http://localhost:1313
  1. 自分のサイトが表示されるか確認する
  2. 確認できたら、黒い画面をクリックして、キーボードで以下を同時に押す
Ctrl + C

(これでプレビューが停止します)

ステップ2:公開用のファイルを作る

  1. 黒い画面に、以下をコピーして貼り付け、Enter
hugo
  1. 少し待って、また文字が表示されたら完了(エラーの赤い文字が出ていなければOK)

ステップ3:サーバーに送る

  1. 黒い画面に、以下の xxx.xxx.xxx.xxx の部分を自分のサーバーのIPアドレスに書き換えてからコピーして貼り付け、Enter
scp -r public\* root@xxx.xxx.xxx.xxx:/var/www/yourlog/public/
  1. たくさんファイル名が流れて、止まったら完了

ステップ4:サーバー側の設定を直す

  1. 黒い画面に、同じように xxx.xxx.xxx.xxx を書き換えてからコピーして貼り付け、Enter
ssh root@xxx.xxx.xxx.xxx
  1. 何か英語の文章がたくさん表示されたら、一番下に # がある行まで待つ
  2. 黒い画面に、以下をコピーして貼り付け、Enter
sudo chmod -R 755 /var/www/yourlog && sudo systemctl restart nginx
  1. また # の行が出てきたら完了

ステップ5:公開されたか確認する

  1. ブラウザを開いて、自分のドメインを入力してEnter(例:https://自分のドメイン名)
  2. サイトが正しく表示されたら、公開完了です

うまくいかないとき

起きたこと やること
黒い画面に Unable to locate config file と出た 一度全部閉じて、「準備:PowerShellを開く」からやり直す
サイトの見た目が崩れて表示される ブラウザで Ctrl + Shift + R を押す
ページが真っ白、または403と表示される ステップ4をもう一度やり直す

うまくいかない場合は、黒い画面に表示された文字(英語の部分)をそのままコピーして、AIへ質問してください。ただし、IPアドレスやパスワードが表示されている部分は、質問する前に隠すか消してください。
