【第2回】機材編 — 必要なPCとソフト、あると便利なもの

2026.09.25

この記事を読み終えると、ブログ構築に必要なPC・ソフト・アカウントがすべて揃った状態になります。

揃えるもの

1. PC

WindowsでもMacでも作れます。目安は次のとおりです。

項目 最低限 おすすめ
メモリ 8GB 16GB(Dockerも使うなら)
空き容量 20GB 50GB以上
OS Windows 10 / macOS Windows 11 / 最新のmacOS

2. ソフト

ソフト 用途 入れ方
Chrome 管理画面の操作・表示確認 公式サイトから
VSCode 記事や設定ファイルを書く 公式サイトから
PowerShell コマンドを打つ Windowsに最初から入っている
Hugo 記事をWebページに変換する 下のコマンド
Git 番外編(GitHub連携)で使う 下のコマンド

HugoとGitはPowerShellで入れます。

winget install Hugo.Hugo.Extended
winget install Git.Git

入ったか確認します。バージョンが表示されればOKです。

hugo version
git --version

3. アカウント

  • Googleアカウント(Search Console・Analytics・AdSenseで使う)
  • GitHubアカウント(番外編で使う。後からでOK)

4. 支払い手段

VPSとドメインの支払いにクレジットカードを用意します。

あると便利なもの

  • パスワード管理アプリ(rootパスワードなどを安全に保管)
  • 作業メモ(打ったコマンドと結果を残しておくと、トラブル時に助かる)
  • 2画面(手順を見ながら操作できる)

つまずきやすい注意点

Windows標準の「メモ帳」で設定ファイルを編集しない

保存するときの文字コードの関係で、文字化けやHugoのエラーの原因になります。必ずVSCodeを使ってください。詳しくは 文字コードの沼 に書きました。

Googleアカウントを短期間にいくつも作らない

ブログ用・連絡用と次々に作った結果、1つが停止されました。ブログ用のアカウントは1つに絞るのが安全です。

学校用と個人用のアカウントを混ぜない

同じPCで学校用のGitHubアカウントを使っていると、個人ブログの作業で認証がぶつかります。番外編で対処法を書いています。

パスワードをメモ帳に書いて保存しない

PCの中を見られたら終わりです。パスワード管理アプリに入れてください。
